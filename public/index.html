תיעוד API

ה-API מאפשר גישה תכנותית לכל הפונקציות של לוח וסתות.

אימות (Authentication)

שלח את מפתח ה-API בכל בקשה באחד מהאופנים:

X-API-Key: vst_your_key_here

או:

Authorization: Bearer vst_your_key_here

ליצירת מפתח: הגדרות → מפתח API → צור מפתח חדש

📋 וסתות (Cycles)

GET /api/cycles

רשימת כל הוסתות

POST /api/cycles

הוספת וסת חדשה

{
  "startDate": "2025-08-30",
  "onah": "day",        // "day" או "night"
  "endDate": null,      // אופציונלי
  "inputFormat": "gregorian"  // או "hebrew"
}

// קלט עברי:
{
  "startDateHeb": { "year": 5786, "month": 7, "day": 6 },
  "onah": "night",
  "inputFormat": "hebrew"
}
POST /api/cycles/import

ייבוא מרובה של וסתות קודמות

// Body:
{
  "records": [
    { "startDate": "2025-08-30", "onah": "day" },
    { "startDate": "2025-09-28", "onah": "night" },
    { "startDate": "2025-10-28", "onah": "night" },
    { "startDate": "2025-11-23", "onah": "day" }
  ]
}

// Response:
{
  "imported": 4,
  "skipped": 0,
  "errors": []
}

// Format per record:
// startDate: YYYY-MM-DD (required)
// onah: "day" or "night" (required)
// endDate: YYYY-MM-DD (optional)
// Max 100 records per request
PUT /api/cycles/:id

עריכת וסת קיימת

DELETE /api/cycles/:id

מחיקת וסת

📅 ימי פרישה (Vestot)

GET /api/vestot

כל ימי הפרישה המחושבים

// תגובה:
{
  "vestot": [
    {
      "id": 1,
      "type": "onah_beinonit",
      "date": "2025-09-28",
      "hebrewDate": { "year": 5786, "month": 7, "day": 6 },
      "onah": "day",
      "is_or_zarua": false,
      "sourceRecordId": 1
    }
  ]
}

// סוגי וסתות:
// onah_beinonit - עונה בינונית (יום 30)
// onah_beinonit_31 - עונה בינונית 31
// haflagah - הפלגה ראשונה
// haflagah_2 - הפלגה שנייה
// haflagah_3 - הפלגה שלישית
// hachodesh - וסת החודש
GET /api/vestot/calendar?from=2025-09-01&to=2025-09-30

ימי פרישה בטווח תאריכים

⚙️ הגדרות (Settings)

GET /api/settings

הגדרות נוכחיות

PUT /api/settings

עדכון הגדרות (שולחים רק את מה שרוצים לשנות)

{
  "posek": "rama",            // "rama" או "mechaber"
  "onah_beinonit_31": true,   // עונה בינונית 31
  "or_zarua": true,           // עונת אור זרוע
  "haflagah_shlishit": true,  // הפלגה שלישית
  "hachodesh_overflow": false  // וסת החודש בל' מלא
}

💡 דוגמה מלאה (cURL)

# רשימת וסתות
curl -H "X-API-Key: vst_your_key" \
  https://veset.dina-ins.co.il/api/cycles

# הוספת וסת
curl -X POST -H "X-API-Key: vst_your_key" \
  -H "Content-Type: application/json" \
  -d '{"startDate":"2025-08-30","onah":"day"}' \
  https://veset.dina-ins.co.il/api/cycles

# ימי פרישה לחודש
curl -H "X-API-Key: vst_your_key" \
  "https://veset.dina-ins.co.il/api/vestot/calendar?from=2025-09-01&to=2025-09-30"

מדיניות פרטיות

האתר משתמש בעוגיית סשן טכנית (httpOnly) לצורך שמירת ההתחברות בלבד. האתר אינו משתמש בעוגיות מעקב, פרסום או אנליטיקה של צד שלישי.
